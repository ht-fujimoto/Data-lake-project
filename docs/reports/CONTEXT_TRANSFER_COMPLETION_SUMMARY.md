## 🎯 ハイブリッドアプローチの仕組み

### アーキテクチャ

```
メタデータカタログ（100データセット）
    │
    │ 同じデータを両方に格納
    │
    ├─ JSON形式（S3）
    │   - 全100件、168KB
    │   - 用途: 軽量検索（90%のクエリ）
    │   - 速度: 0.1秒
    │   - コスト: $0.004/月
    │
    └─ Iceberg形式（Athena）
        - 全100件、500MB
        - 用途: 複雑クエリ（10%のクエリ）
        - 速度: 3-5秒
        - コスト: $0.012/月 + クエリコスト
```

### データの識別方法

**データを分けるのではなく、クエリの種類で使い分ける**:

```python
class HybridDataLakeSearchService:
    def search(self, query, filters=None):
        # クエリの種類を自動判定
        if self._is_complex_query(filters):
            # 集計・GROUP BY・JOINなど → Iceberg使用
            return self._search_with_iceberg(query, filters)
        else:
            # キーワード検索・フィルタ → JSON使用
            return self._search_with_json(query, filters)
```

### 使用例

**軽量検索（JSON使用）**:
```python
# キーワード検索
results = service.search("人口")
# → JSON形式、0.1秒、$0

# ドメインフィルタ
results = service.search("", filters={'domain': 'labor'})
# → JSON形式、0.1秒、$0
```

**複雑クエリ（Iceberg使用）**:
```python
# ドメイン別集計
results = service.search("", filters={
    'aggregate': 'domain',
    'group_by': ['domain', 'priority']
})
# → Iceberg形式、3-5秒、$0.05
```
