## 4. 時間データの扱い

### TIMESTAMP型の問題

```
┌─────────────────────────────────────────────────────────────────┐
│ E-statの多様な時間表現                                             │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  "2020"        → TIMESTAMP型に変換できない ✗                     │
│  "2020Q1"      → TIMESTAMP型に変換できない ✗                     │
│  "2020-01"     → TIMESTAMP型に変換できない ✗                     │
│  "令和2年"     → TIMESTAMP型に変換できない ✗                     │
│  "2020年度"    → TIMESTAMP型に変換できない ✗                     │
│                                                                 │
│  → パースエラーが頻発                                             │
│  → データ投入が失敗                                               │
│  → 情報が失われる（"2020Q1" → "2020-01-01"）                     │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### STRING型 + 補助カラム（推奨）

```
┌─────────────────────────────────────────────────────────────────┐
│ 元データ: "2020Q1"                                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ↓ TimeFieldParserで解析                                         │
│                                                                 │
│  {                                                              │
│    "time_original": "2020Q1",      ← 元の表現を保持              │
│    "time_year": 2020,              ← 年を抽出                    │
│    "time_month": null,             ← 月は該当なし                │
│    "time_quarter": 1,              ← 四半期を抽出                │
│    "time_type": "quarter",         ← タイプを記録                │
│    "time_sort_key": "2020-01-01"   ← ソート用キー                │
│  }                                                              │
│                                                                 │
│  ✓ すべての時間表現に対応                                         │
│  ✓ 元の表現を保持                                                │
│  ✓ 柔軟なクエリが可能                                             │
│  ✓ エラーゼロ                                                    │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

クエリ例:
  - 年で検索:     WHERE time_year = 2020
  - 四半期で検索: WHERE time_year = 2020 AND time_quarter = 1
  - 範囲検索:     WHERE time_sort_key BETWEEN '2020-01-01' AND '2020-12-31'
  - 元の表現:     WHERE time_original = '2020Q1'
```
