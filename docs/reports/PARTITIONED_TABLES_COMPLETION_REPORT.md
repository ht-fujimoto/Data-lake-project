```sql

    table_type = 'ICEBERG',
    format = 'PARQUET',
    location = 's3://estat-feasibility-100/iceberg_partitioned/dataset_XXXXXXXX/',
    is_external = false,
    partitioning = ARRAY['year']
)
AS 
SELECT 
    *,
    CAST(SUBSTRING(attr_time, 1, 4) AS INTEGER) AS year
FROM temp_table
```

### 処理フロー

1. **時間フィールド分析**: `@time`フィールドから年次を抽出
2. **一時テーブル作成**: Parquetファイルから一時的な外部テーブルを作成
3. **Icebergテーブル作成**: `partitioning = ARRAY['year']`でパーティション指定
4. **yearカラム追加**: `SUBSTRING(attr_time, 1, 4)`で年次を計算
5. **一時テーブル削除**: 処理完了後に一時テーブルを削除
6. **検証**: パーティション構造とデータ整合性を確認
