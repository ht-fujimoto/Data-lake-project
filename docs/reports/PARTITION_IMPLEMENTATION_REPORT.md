## 技術的な発見

### 1. Icebergのパーティション指定方法

**誤り**:
```sql
CREATE TABLE table_name
PARTITIONED BY (year)  -- ❌ 構文エラー
WITH (...)
```

**正解**:
```sql
CREATE TABLE table_name
WITH (
    partitioning = ARRAY['year']  -- ✅ 正しい
)
```

### 2. 計算カラムの追加

パーティションカラムは`SELECT`句で計算して追加：

```sql
SELECT 
    *,
    CAST(SUBSTRING(attr_time, 1, 4) AS INTEGER) AS year
FROM temp_table
```

### 3. パーティションプルーニングの条件

パーティションプルーニングが機能する条件：
- パーティションカラムで直接フィルタリング（`WHERE year = 2016`）
- 元のカラムでのフィルタリングは効果なし（`WHERE attr_time LIKE '2016%'`）
