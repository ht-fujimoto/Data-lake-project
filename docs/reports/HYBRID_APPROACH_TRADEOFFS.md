## 🔍 デメリットが問題になるケース

### ケース1: JSON形式のデメリットが問題になる

**状況**: 複雑な集計クエリを実行したい

```python
# JSON形式では困難
# ドメイン別の平均レコード数を計算
results = {}
for ds in catalog['datasets']:
    domain = ds['domain']
    if domain not in results:
        results[domain] = {'count': 0, 'total_records': 0}
    results[domain]['count'] += 1
    results[domain]['total_records'] += ds['record_count']

# 平均を計算
for domain in results:
    results[domain]['avg'] = results[domain]['total_records'] / results[domain]['count']
```

**問題点**:
- ❌ コードが複雑
- ❌ エラーが発生しやすい
- ❌ パフォーマンスが悪い

**解決策**: Iceberg形式に切り替える
```sql
-- シンプルで高速
SELECT domain, AVG(record_count) FROM ... GROUP BY domain
```
