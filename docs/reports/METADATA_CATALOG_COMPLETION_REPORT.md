## 技術的詳細

### データソース
1. **E-stat API**: `getStatsData`でメタデータ取得
2. **AWS Glue**: スキーマ情報取得
3. **Amazon Athena**: データ統計・時間範囲取得

### API制限対策
- 各リクエスト間に0.5秒の待機時間
- タイムアウト: 30秒
- エラーハンドリング: 失敗時もスキップして継続

### 出力ファイル
- `metadata_catalog.json`: 完全なメタデータカタログ（168KB）
- `metadata_catalog_build.log`: 構築ログ
- `test_metadata_search.py`: 検索機能テストスクリプト

### 検索アルゴリズム
**スコアリング方式**:
- タイトルマッチ: +10.0（前方一致: +5.0追加）
- キーワードマッチ: +3.0 × マッチ数
- 説明マッチ: +2.0
- カラム名マッチ: +1.0 × マッチ数
- データ品質ボーナス:
  - 10,000レコード以上: +1.0
  - 時間範囲あり: +0.5

## 使用例

### 基本的な検索
```python
from test_metadata_search import MetadataCatalogSearcher

searcher = MetadataCatalogSearcher('metadata_catalog.json')

# キーワード検索
results = searcher.search("人口")
searcher.print_results(results, max_results=5)
```

### フィルタ付き検索
```python
# ドメインフィルタ
results = searcher.search("労働", filters={'domain': 'labor'})

# レコード数フィルタ
results = searcher.search("", filters={'min_records': 1000000})

# 複合フィルタ
results = searcher.search("", filters={
    'domain': 'economy',
    'priority': 'A',
    'min_records': 10000
})
```
