# 優先度の高いデータセット選択戦略

**目的**: 統計分析の優先度が高い100データセットを選択し、パーティション付きIcebergテーブルでデータレイクを構築

---

## 選択基準

### 1. 統計表の重要度

**優先度A（最重要）**:
- 国勢調査
- 労働力調査
- 家計調査
- 経済センサス
- 人口推計

**優先度B（重要）**:
- 賃金構造基本統計調査
- 毎月勤労統計調査
- 消費者物価指数
- 産業連関表
- 国民経済計算

**優先度C（有用）**:
- 学校基本調査
- 社会生活基本調査
- 住宅・土地統計調査
- 全国消費実態調査

### 2. データの特性

**複数年のデータ**:
- 時系列分析が可能
- パーティション効果が高い
- トレンド分析に有用

**大規模データセット**:
- 10万レコード以上
- パーティション戦略の効果が顕著
- クエリ最適化の重要性が高い

**更新頻度**:
- 月次更新: 労働力調査、消費者物価指数
- 年次更新: 国勢調査、経済センサス
- 定期的な更新があるデータを優先

### 3. 利用頻度

**一般的な分析ニーズ**:
- 人口動態分析
- 労働市場分析
- 経済動向分析
- 地域比較分析

---

## データセット選択方法

### オプション1: E-stat API検索（推奨）

主要な統計表を検索して、関連するデータセットを取得：

```python
# 国勢調査
search_keywords = [
    "国勢調査",
    "労働力調査", 
    "家計調査",
    "経済センサス",
    "人口推計",
    "賃金構造基本統計調査",
    "毎月勤労統計調査",
    "消費者物価指数",
    "学校基本調査",
    "住宅・土地統計調査"
]
```

各キーワードで検索し、上位10データセットを取得（合計100データセット）。

### オプション2: 府省庁別選択

主要な府省庁から均等に選択：

- 総務省統計局: 30データセット（国勢調査、労働力調査など）
- 厚生労働省: 20データセット（賃金構造、毎月勤労統計など）
- 経済産業省: 20データセット（経済センサス、工業統計など）
- 内閣府: 15データセット（国民経済計算、景気動向指数など）
- 文部科学省: 10データセット（学校基本調査など）
- その他: 5データセット

### オプション3: データサイズ順

大規模データセットを優先：

1. レコード数が多いデータセット（100万レコード以上）
2. 複数年のデータを含むデータセット
3. 地域別データを含むデータセット

---

## 推奨アプローチ

**ハイブリッド方式**:

1. **優先度Aの統計表**: 各統計表から10-15データセット（50データセット）
2. **優先度Bの統計表**: 各統計表から5-10データセット（30データセット）
3. **大規模データセット**: レコード数順に20データセット

合計: 100データセット

## 実装計画

### フェーズ1: データセット検索と選択（30分）

1. E-stat APIで主要統計表を検索
2. データセットメタデータを取得
3. 優先度スコアを計算
4. 上位100データセットを選択

### フェーズ2: データ取得とS3保存（1-2時間）

1. 選択した100データセットを取得
2. JSONフォーマットでS3に保存
3. メタデータカタログを作成

### フェーズ3: スキーマ推論とParquet変換（1-2時間）

1. 各データセットのスキーマを推論
2. Parquet形式に変換
3. S3に保存

### フェーズ4: パーティション付きIcebergテーブル作成（2-3時間）

1. 時間フィールドを分析
2. 年次パーティションを設定
3. Athena経由でIcebergテーブルを作成
4. パーティションプルーニングを検証

### フェーズ5: 検証とレポート作成（30分）

1. データ整合性を検証
2. パーティション構造を確認
3. クエリパフォーマンスを測定
4. 完了レポートを作成

**総所要時間**: 5-8時間
