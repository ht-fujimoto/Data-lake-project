# search_estat_data ツール詳細設計書

## 概要
E-stat APIを使用してデータセットを検索するツール。キーワードに基づいて統計表情報を取得します。

## 目的
- E-statの統計表カタログから関連データセットを検索
- データセットIDとメタデータの取得
- データ取り込み前の候補データセット特定

## 入力パラメータ

### 必須パラメータ
- `query` (string): 検索クエリ（キーワード）
  - 例: "人口", "労働力", "経済センサス"

### オプションパラメータ
- `max_results` (integer): 最大結果数
  - デフォルト: 10
  - 範囲: 1-100

## 出力形式

### 成功時
```json
{
  "success": true,
  "query": "検索クエリ",
  "results": [
    {
      "dataset_id": "データセットID",
      "title": "統計表タイトル",
      "organization": "提供組織",
      "survey_date": "調査日",
      "open_date": "公開日",
      "updated_date": "更新日"
    }
  ],
  "count": 結果件数,
  "message": "メッセージ"
}
```

### 失敗時
```json
{
  "success": false,
  "error": "エラー詳細",
  "message": "エラーメッセージ"
}
```

## 処理フロー

1. **環境変数の確認**
   - `ESTAT_APP_ID`の存在確認
   - 未設定の場合はエラー返却

2. **API呼び出し**
   - エンドポイント: `https://api.e-stat.go.jp/rest/3.0/app/json/getStatsList`
   - パラメータ: `appId`, `searchWord`, `limit`
   - タイムアウト: 60秒

3. **リトライロジック**
   - 最大3回のリトライ
   - リトライ間隔: 2秒
   - タイムアウト時の自動リトライ

4. **結果の解析**
   - JSON応答から`TABLE_INF`を抽出
   - 単一オブジェクトの場合はリストに変換
   - 最大`max_results`件まで返却

## エラーハンドリング

### エラーケース
1. **APIキー未設定**
   - エラーコード: `ESTAT_APP_ID environment variable not set`
   - 対処: `.env`ファイルにAPIキーを設定

2. **タイムアウト**
   - 3回のリトライ後もタイムアウト
   - 対処: しばらく待ってから再試行

3. **API呼び出しエラー**
   - ネットワークエラー、HTTPエラー
   - 対処: エラーメッセージを確認して再試行

4. **結果なし**
   - 検索条件に一致するデータセットが存在しない
   - 空の結果リストを返却

## 使用例

### 基本的な検索
```python
{
  "query": "人口",
  "max_results": 5
}
```

### 詳細な検索
```python
{
  "query": "労働力調査 2020年",
  "max_results": 20
}
```

## パフォーマンス考慮事項

- **タイムアウト設定**: 60秒（E-stat APIの応答時間を考慮）
- **リトライ戦略**: 最大3回、2秒間隔
- **結果制限**: デフォルト10件（APIの負荷軽減）

## セキュリティ考慮事項

- APIキーは環境変数から取得（ハードコード禁止）
- HTTPSプロトコルの使用
- タイムアウト設定によるリソース保護

## 依存関係

- `requests`: HTTP通信
- `os`: 環境変数アクセス
- `time`: リトライ待機

## 関連ツール

- `fetch_dataset`: 検索結果のデータセットIDを使用してデータ取得
- `fetch_dataset_auto`: データサイズに応じた自動取得
