# fetch_dataset_auto ツール詳細設計書

## 概要
データセットのサイズを自動判定し、最適な取得方法を選択するツール。小規模データは単一リクエスト、大規模データは分割取得を自動選択します。

## 目的
- データサイズに応じた最適な取得方法の自動選択
- ユーザーがデータサイズを意識せずに取得可能
- タイムアウトやメモリエラーの回避

## 入力パラメータ

### 必須パラメータ
- `dataset_id` (string): データセットID

### オプションパラメータ
- `save_to_s3` (boolean): S3保存フラグ
  - デフォルト: true

## 出力形式

### 小規模データセット（≤100,000件）
`fetch_dataset`の出力形式と同じ

### 大規模データセット（>100,000件）
`fetch_large_dataset_complete`の出力形式と同じ

## 処理フロー

1. **データサイズの事前確認**
   - エンドポイント: `getStatsData`
   - パラメータ:
     - `limit`: 1（最小限のデータ取得）
     - `metaGetFlg`: Y（メタデータ取得）
   - タイムアウト: 60秒

2. **総レコード数の取得**
   - `RESULT_INF.TOTAL_NUMBER`から総数を取得
   - 閾値: 100,000件

3. **取得方法の自動選択**
   - **小規模（≤100,000件）**: `fetch_dataset`を呼び出し
   - **大規模（>100,000件）**: `fetch_large_dataset_complete`を呼び出し

4. **選択されたツールの実行**
   - パラメータを適切に渡す
   - 結果をそのまま返却

## 判定ロジック

### 閾値設定
```python
LARGE_DATASET_THRESHOLD = 100000
```

### 判定条件
```python
if total_number <= LARGE_DATASET_THRESHOLD:
    # 単一リクエスト
    return fetch_dataset(...)
else:
    # 分割取得
    return fetch_large_dataset_complete(...)
```

## エラーハンドリング

### エラーケース
1. **APIキー未設定**
   - エラーメッセージ: "ESTAT_APP_ID environment variable not set"

2. **メタデータ取得失敗**
   - API呼び出しエラー
   - 対処: ネットワーク接続とAPIキーを確認

3. **総レコード数取得失敗**
   - `TOTAL_NUMBER`が存在しない
   - 対処: データセットIDを確認

4. **選択されたツールのエラー**
   - 各ツールのエラーハンドリングに従う

## 使用例

### 基本的な使用
```python
{
  "dataset_id": "0003410379",
  "save_to_s3": true
}
```

### サイズ不明のデータセット
```python
# データサイズを気にせず取得可能
{
  "dataset_id": "unknown_size_dataset"
}
```

## パフォーマンス考慮事項

- **事前確認のオーバーヘッド**: 1回のAPI呼び出し（軽量）
- **最適化効果**: 
  - 小規模データ: 高速な単一リクエスト
  - 大規模データ: 確実な分割取得

## 利点

1. **ユーザビリティ向上**
   - データサイズを意識不要
   - 単一のツールで全サイズ対応

2. **エラー回避**
   - タイムアウトの自動回避
   - メモリ不足の防止

3. **パフォーマンス最適化**
   - 小規模データは高速処理
   - 大規模データは確実に取得

## 制限事項

- **事前確認の必要性**: 1回の追加API呼び出し
- **最大レコード数**: 1,000,000件（大規模取得時）

## セキュリティ考慮事項

- APIキーの環境変数管理
- 各ツールのセキュリティ設定を継承

## 依存関係

- `requests`: メタデータ取得
- `fetch_dataset`: 小規模データ取得
- `fetch_large_dataset_complete`: 大規模データ取得

## 関連ツール

- `fetch_dataset`: 小規模データ取得
- `fetch_large_dataset_complete`: 大規模データ取得
- `fetch_large_dataset_parallel`: 並列大規模取得
- `search_estat_data`: データセット検索

## 推奨使用シーン

- データサイズが不明な場合
- 汎用的なデータ取得スクリプト
- 初めて扱うデータセット
- バッチ処理での複数データセット取得
