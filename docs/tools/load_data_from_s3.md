# load_data_from_s3 ツール詳細設計書

## 概要
S3に保存されたE-statデータを読み込むツール。取得済みデータの再利用や検証に使用します。

## 目的
- S3保存データの読み込み
- データの再処理
- データ内容の確認

## 入力パラメータ

### 必須パラメータ
- `s3_path` (string): S3パス
  - 形式: `s3://bucket/key`
  - 例: `s3://estat-iceberg-datalake/raw/0003410379/data.json`

## 出力形式

### 成功時
```json
{
  "success": true,
  "s3_path": "S3パス",
  "record_count": レコード数,
  "sample": [サンプルレコード（最大3件）],
  "message": "メッセージ"
}
```

### 失敗時
```json
{
  "success": false,
  "error": "エラー詳細",
  "message": "エラーメッセージ"
}
```

## 処理フロー

1. **S3パスの解析**
   - `s3://`プレフィックスの除去
   - バケット名とキーの分離

2. **S3からデータ取得**
   - `boto3.client('s3').get_object()`
   - バイナリデータの読み込み

3. **JSONデコード**
   - UTF-8デコード
   - JSON解析

4. **レコード数のカウント**
   - リスト形式: `len(data)`
   - 単一オブジェクト: 1

5. **サンプルデータの抽出**
   - 最大3件のレコード

## 使用例

### 基本的な読み込み
```python
{
  "s3_path": "s3://estat-iceberg-datalake/raw/0003410379/data.json"
}
```

### プレフィックスなし
```python
{
  "s3_path": "estat-iceberg-datalake/raw/0003410379/data.json"
}
```

## エラーハンドリング

### エラーケース
1. **S3パス不正**
   - 形式エラー
   - 対処: パス形式を確認

2. **バケット不存在**
   - NoSuchBucket
   - 対処: バケット名を確認

3. **キー不存在**
   - NoSuchKey
   - 対処: ファイルパスを確認

4. **権限エラー**
   - AccessDenied
   - 対処: IAMロールを確認

5. **JSONデコードエラー**
   - 不正なJSON形式
   - 対処: ファイル内容を確認

## パフォーマンス考慮事項

- **ファイルサイズ**: メモリに全データを読み込み
- **推奨サイズ**: 100MB以下
- **大容量ファイル**: ストリーミング処理を検討

## セキュリティ考慮事項

- S3アクセスのIAMロール使用
- バケットポリシーの適切な設定
- データの暗号化（S3デフォルト）

## 依存関係

- `boto3`: S3操作
- `json`: JSON解析
- `os`: 環境変数アクセス

## 関連ツール

- `fetch_dataset`: データ取得とS3保存
- `transform_data`: データ変換
- `validate_data_quality`: データ品質検証
