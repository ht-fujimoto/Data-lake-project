# 実装計画: E-statデータレイク構築

## 概要

本実装計画は、11のドメインカテゴリにわたる33のE-statデータセットを含むデータレイクを構築するための段階的なタスクを定義します。各タスクは、既存のE-stat MCPサーバーツールとインフラストラクチャを活用して、データの取得、変換、検証、Icebergテーブルへのロードを実行します。

## タスク

- [x] 1. データセット選択器の実装
  - DatasetSelectorクラスを作成し、各ドメインに適切なE-statデータセットを検索・選択する機能を実装
  - ドメインごとの検索キーワードを設定ファイルに定義
  - E-stat MCP `search_estat_data` ツールを使用してデータセットを検索
  - データセットの新しさ、カバレッジ、更新頻度で優先順位付け
  - 選択されたデータセットをDataset Registryに記録
  - _要件: 1.1, 1.2, 1.3, 1.4_
